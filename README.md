# 🎬 Hunt - Movie Discovery Platform

A modern, responsive movie and TV series exploration app built with **React.js**. This project utilizes the TMDB API to fetch real-time data, providing a seamless cinematic browsing experience.

## Features

- **Dynamic Content:** Browse trending movies and top-rated TV shows.
- **Detailed Pages:** Access deep-dives into movies including overview, cast lists, and trailers.
- **Search Functionality:** Real-time search across thousands of titles.
- **Interactive Sliders:** Smooth, touch-responsive carousels for movie posters.
- **Video Integration:** Built-in YouTube trailer playback.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop screens using SCSS.
